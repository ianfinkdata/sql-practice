Practice prompts paired 1:1 with `curriculum/` — same tier, same file name. Try the prompt yourself before expanding the solution.

| 2 — Intermediate | `02-intermediate/` |
| 3 — Advanced | `03-advanced/` |
| 4 — Expert | `04-expert/` |
| 5 — Master | `05-master/` |

You'll need `project/oakhaven.db` built first — see Tier 0, module 3 (`curriculum/00-orientation/03-tools-and-setup.md`) if you haven't yet.
