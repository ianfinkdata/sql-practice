# Curriculum

> **BLUF (Bottom Line Up Front):** The SQL Practice curriculum is a 6-tier progressive guide (Beginner → Master) taking you from basic `SELECT` statements to designing enterprise star schemas and medallion pipelines.

Six tiers, beginner to master, each building on the last. Start at Orientation if you're brand new or jump into any tier from the list below.

| Tier | Name | Focus |
|---|---|---|
| 0 | [Orientation](00-orientation/) | What a database is, no code required; generating the practice database |
| 1 | [Beginner](01-beginner/) | Asking a database simple questions |
| 2 | [Intermediate](02-intermediate/) | Combining tables, summarizing, cleaning messy real-world data |
| 3 | [Advanced](03-advanced/) | Window functions, CTEs, recursive CTEs, time intelligence — the medallion thread begins |
| 4 | [Expert](04-expert/) | DDL, transactions, views, indexes, query optimization |
| 5 | [Master](05-master/) | Dimensional modeling, star schema design, and the medallion architecture, end to end |

Starting at Tier 3, lessons lean on the real [Oakhaven database](../project/) instead of hypothetical tables — every example and every exercise solution in this curriculum was run against `project/oakhaven.db` and its output verified, not invented.

Each tier's modules are paired 1:1 with practice prompts in [`exercises/`](../exercises/) — same tier folder, same file name.
