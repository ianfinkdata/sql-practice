Tier 1 — Beginner

⚡ BLUF (Bottom Line Up Front)
Tier 1 teaches core single-table SQL querying: selecting columns, filtering rows with WHERE, sorting with ORDER BY, handling NULL values, and computing aggregates across products and employees.
