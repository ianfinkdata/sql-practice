4. The non-messy table

bronze_calendar is the one bronze table that isn't messy — it's a manufactured date spine. Confirm that for yourself: look at its first 3 rows.

Show solution

SQL
SELECT * FROM bronze_calendar LIMIT 3;

Clean, sequential, one row per day — no casing quirks, no missing values. You'll come back to this table much later when doing date-based reporting.

5. Put it together

Without running it first, guess what this query returns, then run it to check:

SELECT * FROM bronze_sales LIMIT 2;
