Exercises: GROUP BY

Curriculum: GROUP BY. Previous: LEFT JOIN and Missing Data. Next: HAVING.

Use project/oakhaven.db. Every solution below was run against the real database — your output should match exactly.

1. Order lines and rough revenue per raw payment_method

Group bronze_sales by payment_method and return the count of rows and the rough total (quantity * unit_price, rounded to 2 decimals) for each, sorted by count descending.

Show solution

SQL
SELECT payment_method, COUNT(*) AS n,
       ROUND(SUM(quantity * unit_price), 2) AS rough_total
FROM bronze_sales
GROUP BY payment_method
ORDER BY n DESC;

Show solution

SQL
SELECT order_status, COUNT(*) AS n, ROUND(AVG(quantity), 2) AS avg_qty
FROM bronze_sales
GROUP BY order_status
ORDER BY n DESC;

Note the blank/NULL row: `GROUP BY` treats `NULL` as its own group (it doesn't get dropped or error), which is worth knowing before you assume a grouped report accounts for 100% of rows just because the numbers "look complete."

4. Two-column GROUP BY: employee count per department + region combination

Group bronze_employees by both department and region together, and return the first 10 rows ordered by department, then region.

Show solution

SQL
SELECT department, region, COUNT(*) AS n
FROM bronze_employees
GROUP BY department, region
ORDER BY department, region

Small groups like this are exactly why Module 4's `HAVING` exists — to filter down to only the combinations worth looking at.

5. Top 5 brands by product count, with their price range

Group bronze_products by brand, returning count of products, minimum unit_price, and maximum unit_price — top 5 by product count.

Show solution

SQL
SELECT brand, COUNT(*) AS n, MIN(unit_price) AS min_price, MAX(unit_price) AS max_price
FROM bronze_products
GROUP BY brand
ORDER BY n DESC
LIMIT 5;

6. Which raw category spellings does each channel favor?

Group bronze_sales joined to bronze_products by both channel and category, restricted to the three raw spellings of "Climbing" ('Climbing', 'CLIMBING', 'climbing'), returning line counts. Order by channel, then category.

Show solution

SQL
SELECT s.channel, p.category, COUNT(*) AS n
FROM bronze_sales s
JOIN bronze_products p ON s.product_id = p.product_id
WHERE p.category IN ('Climbing', 'CLIMBING', 'climbing')
GROUP BY s.channel, p.category
ORDER BY s.channel, p.category;
